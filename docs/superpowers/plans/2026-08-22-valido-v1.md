# Valido V1 — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** livrer un feed vertical infini de questions à choix multiples (code de la route + Swift) dont le verdict est asymétrique et le tirage imprévisible.

**Architecture :** toute la logique vit dans un paquet SwiftPM local `ValidoCore` sans dépendance à SwiftUI — modèle, banque de questions, progression, scheduler, combo, et le modèle de feed observable. La cible Xcode `Valido` ne contient que des vues. Le scheduler est une fonction pure à RNG et horloge injectés ; l'horloge est un compteur de cartes servies, pas une date.

**Tech Stack :** Swift 6.2.4, Swift Testing (`import Testing`), SwiftPM local, SwiftUI, iOS 26.2, Xcode 26.3 (`DEVELOPER_DIR=/Applications/Xcode-26.3.0.app`). Notion MCP pour l'import unique du contenu.

**Spec :** `docs/superpowers/specs/2026-08-22-valido-design.md`

## Écarts assumés par rapport à la spec et à la skill

1. **§5 de la spec est remplacé** par l'arborescence de ce plan : la logique passe dans
   `ValidoCore/` (paquet SwiftPM local) au lieu de `Valido/Content/`, `Valido/Feed/`, etc.
   Les frontières entre unités sont inchangées ; seul le conteneur change. Motif : `swift test`
   tourne en ~1 s sans simulateur, et le `.pbxproj` n'est touché qu'à la tâche 8.
2. **Pas d'étape de commit.** Le projet n'est pas un dépôt git et Guillaume a demandé de ne rien
   versionner. Chaque tâche se termine par un **point de contrôle** — la suite complète au vert —
   là où la skill writing-plans prévoit un commit.
3. **La tâche 8 comporte une étape manuelle dans Xcode.** Ajouter une dépendance de paquet local
   demande une modification du `.pbxproj` qu'un agent corrompt facilement ; l'interface graphique
   fait la même chose en vingt secondes. La procédure manuelle d'édition est fournie en repli.

## Global Constraints

Valeurs reprises telles quelles de la spec. Elles s'appliquent à toutes les tâches.

- Part de tirage pondéré : **70 %** ; part de tirage uniforme garanti : **30 %**.
- Fenêtre anti-répétition : **25** dernières cartes servies.
- Poids d'échec : **3.0** si jamais vue, sinon `0.3 + 2.7 × (fautes / tentatives)`.
- Poids d'ancienneté : `max(0.05, min(1.0, (serveIndex - lastServeIndex) / 60))`, **1.0** si jamais vue.
- Auto-avance sur bonne réponse : **400 ms**. Verdict visuel : **< 100 ms**.
- Le combo devient « chaud » à partir de **×5**.
- Écriture disque groupée : toutes les **5** réponses, ou au changement de scène.
- Cible : **iOS 26.2**. `SWIFT_VERSION` de la cible app à passer de **5.0 à 6.0**.
- **Aucun `git init`, aucun commit, aucune commande git.**
- Options **mélangées une seule fois au moment du tirage**, jamais dans une vue.
- Un seul type de carte : `.question`. Pas de carte boss, pas de série, pas de notifications.

```swift
import Foundation

public enum Subject: String, Codable, Sendable, CaseIterable {
    case code
    case swift
}

public enum Difficulty: String, Codable, Sendable, CaseIterable {
    case facile
    case moyen
    case costaud
}

public struct Option: Identifiable, Codable, Sendable, Hashable {
    public let id: String   // la lettre d'origine Notion : "A", "B", "C", "D"
    public let text: String

    public init(id: String, text: String) {
        self.id = id
        self.text = text
    }
}

public struct Question: Identifiable, Codable, Sendable, Hashable {
    public let id: String   // ID de page Notion
    public let subject: Subject
    public let topic: String
    public let difficulty: Difficulty
    public let prompt: String
    public let options: [Option]
    public let correctID: Option.ID
    public let explanation: String
    public let sourceURL: URL?

    public init(
        id: String,
        subject: Subject,
        topic: String,
        difficulty: Difficulty,
        prompt: String,
        options: [Option],
        correctID: Option.ID,
        explanation: String,
        sourceURL: URL? = nil
    ) {
        self.id = id
        self.subject = subject
        self.topic = topic
        self.difficulty = difficulty
        self.prompt = prompt
        self.options = options
        self.correctID = correctID
        self.explanation = explanation
        self.sourceURL = sourceURL
    }

    public func isCorrect(_ optionID: Option.ID) -> Bool {
        optionID == correctID
    }
}
```

- [ ] **Step 4: Écrire `QuestionBank.swift`**

```swift
import Foundation

public struct QuestionBank: Sendable {
    public let questions: [Question]
    private let byID: [Question.ID: Question]

    public init(questions: [Question]) throws {
        guard !questions.isEmpty else { throw ContentError.emptyBank }

        var index: [Question.ID: Question] = [:]
        for question in questions {
            guard index[question.id] == nil else {
                throw ContentError.duplicateID(question.id)
            }
            guard question.options.count >= 2 else {
                throw ContentError.tooFewOptions(question.id)
            }
            guard question.options.contains(where: { $0.id == question.correctID }) else {
                throw ContentError.correctIDNotInOptions(question.id)
            }
            guard !question.explanation.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty else {
                throw ContentError.emptyExplanation(question.id)
            }
            index[question.id] = question
        }

        self.questions = questions
        self.byID = index
    }

    public init(json: Data) throws {
        try self.init(questions: try JSONDecoder().decode([Question].self, from: json))
    }

    public static func bundled() throws -> QuestionBank {
        guard let url = Bundle.module.url(forResource: "questions", withExtension: "json") else {
            throw ContentError.resourceMissing
        }
        return try QuestionBank(json: try Data(contentsOf: url))
    }

    public var count: Int { questions.count }

    public func question(id: Question.ID) -> Question? { byID[id] }
}
```

La validation vit ici *en plus* de l'import. C'est voulu : elle coûte moins d'une milliseconde sur
250 questions, et c'est elle qui donne du contenu au test de la tâche 3.

- [ ] **Step 2: Lire les 250 corps de page**

`notion-fetch` sur chaque `url`, par lots parallèles d'environ 20 appels. Le corps a cette forme :

```
- A. 110 km/h
- B. 100 km/h
- C. 90 km/h
- D. 80 km/h
<details>
<summary>👀 Réponse</summary>
	**B — 100 km/h.** Sous la pluie : 130→110, 110→100, 90→80. Les 80 km/h restent 80.
</details>
```

- [ ] **Step 3: Analyser chaque page selon ces règles**

- `id` : l'UUID de page **sans tirets** tel qu'il apparaît dans l'URL (`37fe1af42b8d818da27dc338f75795fe`).
- `subject` : `code` pour `QCM Code`, `swift` pour `Quiz Swift`.
- `topic` : la propriété `Thème` ou `Section`, telle quelle.
- `difficulty` : `Facile` → `facile`, `Moyen` → `moyen`, `Costaud` → `costaud`.
- `prompt` : la propriété `Question` (le titre de la page).
- `options` : chaque ligne du corps qui correspond à `^-\s+([A-D])\.\s+(.+)$` ;
  groupe 1 → `Option.id`, groupe 2 → `Option.text` détrimé.
- `correctID` : dans le bloc `<details>`, la première lettre en gras — motif
  `\*\*\s*([A-D])\s*[—–\-.)]` .
- `explanation` : le texte du bloc `<details>`, duquel on retire **le marqueur de lettre et les
  astérisques**. Retirer `^\*\*\s*[A-D]\s*[—–\-.)]?\s*` puis toutes les paires `**`.
  Sur l'exemple ci-dessus le résultat est
  `100 km/h. Sous la pluie : 130→110, 110→100, 90→80. Les 80 km/h restent 80.`
- `sourceURL` : la propriété `Page` si elle est non vide (`Quiz Swift` seulement), sinon absente.

**Le retrait du marqueur de lettre n'est pas cosmétique.** Les options sont mélangées à
l'affichage : une explication qui commence par « B — » désigne une lettre qui n'existe plus,
et trahit la bonne réponse à la question suivante si l'utilisateur retient la lettre.

```swift
    public var failures: Int
```

```swift
import Foundation

public struct CardScheduler: Sendable {
    public let config: SchedulerConfig

    public init(config: SchedulerConfig = SchedulerConfig()) {
        self.config = config
    }

    public func next(
        bank: QuestionBank,
        progress: ProgressSnapshot,
        recent: [Question.ID],
        rng: inout some RandomNumberGenerator
    ) -> ScheduledCard {
        let pool = eligible(in: bank, recent: recent)
        let uniforme = Double.random(in: 0..<1, using: &rng) >= config.weightedShare

        let choisie = uniforme
            ? pool.randomElement(using: &rng)!
            : weightedPick(from: pool, progress: progress, rng: &rng)

        let présentée = PresentedQuestion(
            question: choisie,
            displayOptions: choisie.options.shuffled(using: &rng)
        )

        return ScheduledCard(card: .question(présentée), draw: uniforme ? .uniform : .weighted)
    }

    public func weight(for id: Question.ID, progress: ProgressSnapshot) -> Double {
        let stats = progress.stats(for: id)

        guard let lastServeIndex = stats.lastServeIndex else {
            return config.unseenFailureWeight
        }

        let échec = config.baseFailureWeight + config.failureSpan * stats.failureRate
        let écoulé = Double(progress.serveIndex - lastServeIndex)
        let ancienneté = max(config.recencyFloor, min(1.0, écoulé / config.recencyHorizon))

        return échec * ancienneté
    }

    /// Retire les `recentWindow` dernières cartes servies. Si plus rien n'est éligible
    /// — banque plus petite que la fenêtre — la fenêtre est tronquée par son extrémité
    /// la plus ancienne jusqu'à ce qu'un tirage redevienne possible.
    private func eligible(in bank: QuestionBank, recent: [Question.ID]) -> [Question] {
        var fenêtre = Array(recent.suffix(config.recentWindow))

        while true {
            let exclus = Set(fenêtre)
            let pool = bank.questions.filter { !exclus.contains($0.id) }
            if !pool.isEmpty { return pool }
            if fenêtre.isEmpty { return bank.questions }
            fenêtre.removeFirst()
        }
    }

    private func weightedPick(
        from pool: [Question],
        progress: ProgressSnapshot,
        rng: inout some RandomNumberGenerator
    ) -> Question {
        let poids = pool.map { weight(for: $0.id, progress: progress) }
        let total = poids.reduce(0, +)

        guard total > 0 else { return pool.randomElement(using: &rng)! }

        var tirage = Double.random(in: 0..<total, using: &rng)
        for (question, poids) in zip(pool, poids) {
            tirage -= poids
            if tirage < 0 { return question }
        }
        return pool[pool.count - 1]
    }
}
```

```swift
public struct ComboEngine: Sendable, Equatable {
```

- [ ] **Step 3: Écrire l'effaceur de RNG puis `FeedModel.swift`**

`FeedModel` doit stocker un RNG et le passer en `inout` au scheduler. Un stockage en
`any RandomNumberGenerator` **ne compile pas** : Swift n'ouvre pas un existentiel pour un
paramètre `inout some`. Un effaceur concret règle le problème sans rendre `FeedModel` générique,
ce qui compte parce que trois vues le nomment directement.

```swift
/// Efface le type d'un générateur pour pouvoir le stocker et le passer en `inout`.
/// Sémantique de référence assumée : deux copies partagent la même suite tirée.
public struct AnyRandomNumberGenerator: RandomNumberGenerator {
    private final class Box<R: RandomNumberGenerator> {
        var base: R
        init(_ base: R) { self.base = base }
    }

    private let advance: () -> UInt64

    public init(_ base: some RandomNumberGenerator) {
        let box = Box(base)
        advance = { box.base.next() }
    }

    public func next() -> UInt64 { advance() }
}
```

```swift
import Foundation
import Observation

@MainActor
@Observable
public final class FeedModel {
    /// Cartes préparées devant la position courante.
    public static let lookahead = 3
    /// Cartes conservées derrière la position courante, pour permettre de remonter.
    public static let trail = 5
    /// Borne dure sur la fenêtre glissante.
    public static let maxWindow = lookahead + trail + 2
    /// Nombre de réponses entre deux écritures disque.
    public static let saveEvery = 5

    public private(set) var cards: [Card] = []
    public private(set) var combo = ComboEngine()
    /// Index absolu, dans le flux, de `cards[0]`.
    public private(set) var firstIndex = 0

    private let bank: QuestionBank
    private let store: any ProgressStore
    private let scheduler: CardScheduler
    private var rng: AnyRandomNumberGenerator
    private var progress: ProgressSnapshot
    private var recent: [Question.ID] = []
    private var answered: Set<Question.ID> = []
    private var unsavedAnswers = 0

    public init(
        bank: QuestionBank,
        store: any ProgressStore,
        scheduler: CardScheduler = CardScheduler(),
        rng: some RandomNumberGenerator = SystemRandomNumberGenerator()
    ) {
        self.bank = bank
        self.store = store
        self.scheduler = scheduler
        self.rng = AnyRandomNumberGenerator(rng)
        self.progress = store.load()
    }

    public func start() {
        guard cards.isEmpty else { return }
        for _ in 0..<Self.lookahead { appendCard() }
    }

    /// Alimente la fenêtre devant `currentIndex` et coupe la traîne derrière.
    ///
    /// Terminaison : `firstIndex + cards.count` — l'index juste après la dernière carte —
    /// croît strictement à chaque tour (un `appendCard` l'augmente de 1, un `trimFront`
    /// le laisse inchangé), donc la condition finit par être fausse.
    public func ensureCards(currentIndex: Int) {
        while firstIndex + cards.count <= currentIndex + Self.lookahead {
            appendCard()
            while cards.count > Self.maxWindow { trimFront() }
        }
        while currentIndex - firstIndex > Self.trail {
            trimFront()
        }
    }

    /// Rend `true` si la réponse est bonne. Une deuxième réponse sur la même carte est ignorée.
    public func answer(_ optionID: Option.ID, at index: Int) -> Bool {
        guard let card = card(at: index), let presented = card.presented else { return false }
        let correct = presented.question.isCorrect(optionID)

        guard !answered.contains(presented.id) else { return correct }
        answered.insert(presented.id)

        combo.answer(correct: correct)
        progress.recordAnswer(presented.id, correct: correct)
        unsavedAnswers += 1
        if unsavedAnswers >= Self.saveEvery { flush() }

        return correct
    }

    public func dismissExplanation() {
        combo.dismissExplanation()
    }

    public func flush() {
        unsavedAnswers = 0
        try? store.save(progress)
    }

    public func card(at index: Int) -> Card? {
        let offset = index - firstIndex
        guard cards.indices.contains(offset) else { return nil }
        return cards[offset]
    }

    private func appendCard() {
        let scheduled = scheduler.next(bank: bank, progress: progress, recent: recent, rng: &rng)
        cards.append(scheduled.card)
        progress.recordServe(scheduled.card.id)
        recent.append(scheduled.card.id)
        if recent.count > scheduler.config.recentWindow {
            recent.removeFirst(recent.count - scheduler.config.recentWindow)
        }
    }

    private func trimFront() {
        guard !cards.isEmpty else { return }
        cards.removeFirst()
        firstIndex += 1
    }
}
```

- [ ] **Step 3: Écrire `FeedView.swift`**

Pagination verticale sur une fenêtre glissante, jamais sur la banque entière. L'auto-avance de
400 ms ne se déclenche que si `model.combo.advancesAutomatically` est vrai — c'est-à-dire sur

```swift
import SwiftUI
import ValidoCore

struct FeedView: View {
    let model: FeedModel
    @Environment(\.scenePhase) private var scenePhase
    @State private var position: Int = 0

    var body: some View {
        ScrollView(.vertical) {
            LazyVStack(spacing: 0) {
                ForEach(Array(model.cards.enumerated()), id: \.element.id) { offset, card in
                    let index = model.firstIndex + offset
                    Group {
                        switch card {
                        case .question(let presented):
                            QuestionCardView(
                                presented: presented,
                                combo: model.combo,
                                onAnswer: { optionID in
                                    let correct = model.answer(optionID, at: index)
                                    if correct { advance(after: index, delay: 0.4) }
                                    return correct
                                },
                                onDismiss: {
                                    model.dismissExplanation()
                                    // Immédiat : le balayage est déjà le geste de l'utilisateur.
                                    advance(after: index, delay: 0)
                                }
                            )
                        }
                    }
                    .containerRelativeFrame(.vertical)
                    .id(index)
                }
            }
            .scrollTargetLayout()
        }
        .scrollTargetBehavior(.paging)
        .scrollPosition(id: Binding(
            get: { position },
            set: { position = $0 ?? position }
        ))
        .ignoresSafeArea(edges: .bottom)
        .onAppear { model.start() }
        .onChange(of: position) { _, new in model.ensureCards(currentIndex: new) }
        .onChange(of: scenePhase) { _, phase in
            if phase != .active { model.flush() }
        }
    }

    /// `delay` vaut 0.4 s après une bonne réponse — le temps de voir le vert — et 0
    /// après un balayage, où l'utilisateur a déjà demandé à avancer.
    private func advance(after index: Int, delay: Double = 0.4) {
        model.ensureCards(currentIndex: index)
        withAnimation(.snappy(duration: 0.35).delay(delay)) {
            position = index + 1
        }
    }
}
```
